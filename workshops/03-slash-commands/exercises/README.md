# Workshop 03 — Slash Commands: вправи

Чотири вправи по 10–15 хвилин кожна. Слайди ведуть — ти кодиш паралельно.

## Передумови

- Claude Code v1.x встановлений (`claude --version`)
- Доступ до `~/.claude/` (для встановлення особистих команд)
- Git-репо для тестових команд (можна цей)

## Маршрут

| № | Тека | Що робиш | Час |
|---|---|---|---|
| 1 | `01-git-summary/` | `/git-summary` з `$ARGUMENTS` (e.g. `--since=yesterday`) | 10 хв |
| 2 | `02-shell-injection/` | Додати `!`команду`` — гілка, останній коміт, env | 10 хв |
| 3 | `03-allowed-tools/` | Команда з `allowed-tools` лише для `git` | 15 хв |
| 4 | `04-plugin-pack/` | Дві команди → плагін з namespaced invocation | 15 хв |

## Як запускати

Кожна тека має свій `README.md`. Загалом:

```bash
cd 0N-name/
cat README.md          # інструкція
ls starter/            # стартовий стан
# роби кроки з README
ls ../solutions/0N-*/  # підглянь якщо застрягнеш
```

## solutions/

Готові розв'язки. Не дивись, поки не спробував — мета не «скопіювати», а зрозуміти різницю.

## Що зберіг після воркшопу

- Робочий `/git-summary` з аргументами і shell-ін'єкцією
- Плагін `my-git-commands` з двома namespaced командами
- Шаблон `plugin.json` для своїх майбутніх плагінів
- Розуміння `allowed-tools` vs deny-rules
