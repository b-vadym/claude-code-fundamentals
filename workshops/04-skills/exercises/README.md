# Workshop 04 — Skills: вправи

Чотири вправи по 10–15 хвилин кожна. Слайди ведуть — ти кодиш паралельно.

## Передумови

- Claude Code v1.x встановлений (`claude --version`)
- Доступ до `~/.claude/` (для встановлення особистих skill-ів)
- Git-репо для тестових команд (можна цей)

## Маршрут

| № | Тека | Що робиш | Час |
|---|---|---|---|
| 1 | `01-first-skill/` | Перший skill `git-status-summary` встановлений локально | 10 хв |
| 2 | `02-trigger-tuning/` | Порівняти 3 description-стратегії на одному skill | 15 хв |
| 3 | `03-progressive-disclosure/` | Розбити роздутий 600-рядковий skill на SKILL.md + references/ | 15 хв |
| 4 | `04-package-skill/` | Спакувати 2 skill-и у плагін з `plugin.json` | 15 хв |

## Як запускати

Кожна тека має свій `README.md` зі специфічними кроками. Загалом:

```bash
cd 0N-name/
cat README.md          # інструкція
ls starter/            # стартовий стан
# роби кроки з README
ls ../solutions/0N-*/  # підглянь якщо застрягнеш
```

## solutions/

Готові розв'язки для кожної вправи. Не дивись поки не спробував сам — мета не «скопіювати», а зрозуміти різницю між твоїм підходом і еталоном.

## Коли застрягнеш

- Спочатку — `solutions/`
- Потім — `handout.pdf` у батьківській теці
- Питання — Discord або підніми руку на воркшопі

## Що зберіг після воркшопу

- Робочий skill `git-status-summary` у `~/.claude/skills/`
- Розуміння як писати description, що тригерить
- Шаблон `plugin.json` для майбутніх своїх плагінів
- Список 6 кроків діагностики, коли skill не тригериться
