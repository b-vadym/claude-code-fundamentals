# Сценарій

Понеділок, 9:32 ранку. Ти отримуєш повідомлення від tech-lead-а:

> "Привіт. Хвилин 10 тому помітив що у `CLAUDE.md` потрапив наш Anthropic API ключ. Не знаю коли точно — кілька комітів тому. Я зараз йду його ротувати у Console. Тобі: вичисти з git історії і скажи коли все. Не чіпай force-push поки я не скажу — я координую з командою."
>
> "Ключ виглядає як `sk-ant-FAKEFAKEFAKE_FAKE_FAKE_FAKE_KEY_001`. Можливо є ще один — `sk-ant-FAKEFAKEFAKE_FAKE_FAKE_FAKE_KEY_002` від попереднього юзера. Прочеши обидва."

Repo у `repo/`. Не push-ай нічого до зовнішніх систем. Це навчальна симуляція — usually 0 ключі ніколи активні.

## Що від тебе чекають

1. Знайти всі instance ключів у history
2. (Симуляція) ротація — створити `ROTATED.md` з timestamp і відмаркуванням
3. `git filter-repo` для cleanup
4. Підтвердити що чисто
5. Написати `INCIDENT.md` для post-mortem

## Чого НЕ робити

- НЕ запускай `git push --force` (lead координує)
- НЕ копіюй ключ нікуди (це не справжній, але звичка важлива)
- НЕ `git rebase -i` для cleanup — filter-repo надійніший
