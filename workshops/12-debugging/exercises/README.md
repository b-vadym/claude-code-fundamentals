# Workshop 12 — Debugging: вправи

Чотири вправи по 10–15 хвилин. У кожному `starter/` навмисно зламано — твоя задача знайти і виправити.

## Передумови

- Claude Code v1.x встановлений (`claude --version`)
- `jq` встановлений (`brew install jq` / `apt install jq`)
- Python 3 (для вправи 3 — простий MCP-сервер)
- Доступ до `~/.claude/` (для personal skills у вправі 2)

## Маршрут

| № | Тека | Що робиш | Час |
|---|---|---|---|
| 1 | `01-broken-hook/` | Hook не блокує — знайди 3 баги | 15 хв |
| 2 | `02-skill-trigger/` | Skill з vague description — переписати | 10 хв |
| 3 | `03-mcp-config/` | `.mcp.json` зламаний — знайди обидва баги | 10 хв |
| 4 | `04-transcript-jq/` | Розслідуй context loss після compaction через jq | 15 хв |

## Як запускати

```bash
cd 0N-name/
cat README.md          # умова + підказки
ls starter/            # стартовий зламаний стан
# роби кроки з README
ls ../solutions/0N-*/  # підглянь якщо застрягнеш (не одразу!)
```

## solutions/

Готові розв'язки для кожної вправи. **Не дивись поки не спробував.** Мета — натренувати муск­ульну пам'ять діагностики, а не швидко скопіювати.

## Коли застрягнеш

- Спочатку — пройди 6-крокову діагностику зі слайдів
- Потім — `solutions/`
- Потім — `handout.pdf` у батьківській теці
- Питання — Discord або руку на воркшопі

## Що залишиш після воркшопу

- Робочий PreToolUse hook що блокує `rm -rf`
- Skill з надійним description
- Working `.mcp.json` для тестового MCP-сервера
- Уміння читати session transcripts через jq
